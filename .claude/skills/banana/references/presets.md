# Brand/Style Presets Reference

## Storage Format

Presets are stored as JSON files in `~/.banana/presets/NAME.json`, containing color palette, visual style, typography, lighting, mood, and default dimensions.

## Example Presets

- **Tech-SaaS**: blue tones (#2563EB, #1E40AF, #F8FAFC), minimal flat vector illustrations
- **Luxury-Brand**: dark and gold (#1A1A1A, #C9A96E, #FAFAF5), elegant high-end photography
- **Editorial-Magazine**: black/white with red accents (#000000, #FFFFFF, #FF3B30), bold composition

## Precedence

User-specified instructions always override preset defaults.
